# Opmiz plugin

The Opmiz plugin for Claude: the Opmiz connector, plus skills for building and running websites, shops and content on [Opmiz](https://www.opmiz.com).

```
claude plugin marketplace add opmiz-wbos/opmiz-plugin
claude plugin install opmiz@opmiz
```

See [the plugin's README](opmiz/README.md) for what it does and what it connects to. Documentation for AI apps is at [docs.opmiz.com](https://docs.opmiz.com).
